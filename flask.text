Динамические маршруты

@app.route("/post/<int:post_id>")
def post(post_id):
    return f"Вы просматриваете пост с ID: {post_id}"
В этом примере post/ — это статическая часть маршрута, которая не меняется.

post — означает, что мы работаем с постами (например, читаем или редактируем).
Эта часть всегда остаются одинаковой и помогает организовать структуру адресов.

Здесь <int:post_id> — это динамическая часть маршрута. Flask автоматически извлекает значение из URL и передаёт его в функцию.

Когда пользователь заходит на post/4, Flask:

Сравнивает адрес с маршрутом @app.route("post/<int:post_id>").
Видит, что <int:post_id> — это переменная, которая должна быть целым числом.
Извлекает 4 из URL и передаёт его в аргумент post_id функции post().
Значение post_id можно использовать, чтобы, например, найти нужный пост в базе данных:

@app.route("post/<int:post_id>")
def post(post_id):
    # Пример логики
    post = find_post_by_id(post_id)  # Здесь мы ищем пост в базе данных
    if post:  # Если пост найден
        return f"Пост с ID {post_id}: {post.title}"  # Возвращаем его содержимое
    else:
        return "Пост не найден."  # Показываем сообщение об ошибке
Если в базе данных есть пост с таким ID, Flask его "вытащит" и покажет пользователю в виде HTML-страницы. 

Flask позволяет создавать маршруты, где часть URL может быть динамической, например, /post/4 или /user/Islam. Для таких динамических маршрутов можно указать тип данных, которые будут приниматься:

string (по умолчанию): принимает любой текст, кроме символа /.
int: принимает только положительные целые числа.
float: принимает положительные числа с десятичной точкой.
uuid: принимает строки в формате UUID (уникальные идентификаторы).

1) Профили пользователей:

@app.route("/user/<string:username>")
def user_profile(username):
    return f"Вы просматриваете профиль пользователя: {username}"

2) Посты или статьи:
@app.route("/post/<int:post_id>")
def post(post_id):
    return f"Вы читаете пост с ID: {post_id}"

Пример реализации в Flask
Представим, что у нас есть простая база данных users в виде словаря, и маршрут, который ищет пользователя в базе данных и показывает информацию о нем в виде HTML страницы

from flask import Flask

app = Flask(__name__)

# Пример базы данных
users = {
    1: {"name": "Ислам", "city": "Уфа", "age": 32},
    2: {"name": "Мария", "city": "Акъяр", "age": 18},
    3: {"name": "Абдулла", "city": "Сибай", "age": 20}
}

@app.route("/users/<int:user_id>")
def user_profile(user_id):
    user = users.get(user_id, False)
    if user:
        # Если пользователь найден, возвращаем его данные
        return f"""
        <h1>Профиль пользователя</h1>
        <p>Имя: {user['name']}</p>
        <p>Город: {user['city']}</p>
        <p>Возраст: {user['age']}</p>
        """
    else:
        # Если пользователь не найден
        return "Пользователь не найден"

if __name__ == "__main__":
    app.run(debug=True)
